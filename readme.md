# Game Bot
The most productive fun game hosting bot loaded with jokes, availible on Slack!
![Site Preview](bot.png)
### Try it!
You can try the bot out by downloading the .zip from https://github.com/MasterCoder360/SlackBot/releases/tag/Tryit. You need to host it locally(or even cloud) run```npm init -y
npm install @slack/bolt

```
to install dependencies and packages and then unzip the file. Create a .env file with ```export SLACK_APP_TOKEN= 
export SLACK_SIGNING_SECRET=
export SLACK_BOT_TOKEN=


```
And then in slack /invite @GameBot (or your bot name)
